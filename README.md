# Official LDraw.org Library

This is the official repo for the [LDraw.org Library](https://library.ldraw.org)

This repo was built using the ldraw027 package as a base and applying all incremental updates from 9615 to present.

While LDraw is a case-insensitive language, for consistancy, all parts (and some other non-part) file names were normalized
to all lower case during repo creation.

Parts update 2008-01 was a complete reissue of the library that removed the need to download both ldraw027 and the 
complete update rollup.  As such, this repo was created such that 2008-01 represent a complete reset (except release 
notes in the model directory) of all files.
